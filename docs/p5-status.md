## 1. 处理顺序（已更新）

```
幂等 → 群状态 → 空内容 → 滥用 → 全局频率 → 群频率 → 每日额度
   → 指令路由 ──命中──► 直接回复

                      │
```

## 2. 指令

| 指令 | 别名 | 说明 |
|---|---|---|
| `/help` | `/帮助` | 按当前模式显示可用指令 |
| `/mode <模式>` | `/模式` | `trpg` / `minigame` / `off` |
| `/roll <表达式>` | `/r` | 掷骰，缺省 `1d20` |
| `/check <标签>` | `/c` | 裸骰检定（只报 d20） |
| `/pc` | `/角色卡` | P6 上线 |

- 支持半角 `/` 与全角 `／`
- 指令名大小写不敏感
- 未知指令返回提示，不会落到模型

### 骰子语法

| 写法 | 含义 |
|---|---|
| `1d20` | 一颗二十面骰 |
| `d100` | 省略数量，默认 1 |
| `3d6+2` | 三颗六面骰加 2 |
| `2d20kh1` | 两颗取高 |
| `2d20kl1` | 两颗取低 |
| `1d8+1d6+3` | 多项混合 |

限制：最多 8 项、单次最多 100 颗、面数 2–1000。每次投骰带种子，可复现。

## 3. 模式

| 模式 | 行为 |
|---|---|
| `chat`（默认） | 指令 + 正常聊天 |
| `trpg` | 只响应指令，闲聊**静默** |
| `minigame` | 同上 |

- 模式是**群级**状态，存在 `groups.mode`
- 切换权限：群主 / 群管理员（`member_role ∈ {owner, admin}`）
- 每次切换写审计
- `/mode off` 回到 chat

> 跑团模式下 bot 不调用模型，这一点与架构里的 D16 一致。

## 4. 在线参数

管理界面「运行参数」可即时调整，无需重启：

| 参数 | 范围 |
|---|---|
| 警告阈值 | 1–100 |
| 静默阈值 | 1–100 |
| 统计窗口 | 10–3600 秒 |
| 警告冷却 | 0–86400 秒 |
| 单群频率 | 1–600 qpm |
| 全局频率 | 1–600 qpm |
| 每日消息额度 | 0–1,000,000（**0 = 不限**） |
| 每日 Token 额度 | 0–100,000,000（**0 = 不限**） |
| 上下文保留条数 | 2–100 |
| 单次最大输出 | 64–32000 |

每项在界面上都带一句说明（它到底影响什么），避免"没人记得这个数字是干嘛的"。

保存后立即生效并写入 `config/instance.yaml`。
