# 群内指令手册

所有指令都以 `/` 或 `／` 开头。只有群里 @ 机器人时才会被处理。

指令按模式隔离：

| 模式 | 响应范围 |
|---|---|
| chat | 通用指令 + 小游戏 |
| trpg | 通用指令 + 跑团指令（含规则 hook） |
| minigame | 通用指令 + 小游戏 |
| 自定义模式 | 通用指令 + 小游戏 |

通用指令：`/help`、`/mode`、`/game`、`/wiki`。

不在范围内的指令直接不响应；`/mode` 不带参数显示当前模式，不会切换。

---

## 一、通用

| 指令 | 说明 |
|---|---|
| `/help` | 查看当前模式可用指令，末尾附已启用插件和小游戏指令 |
| `/mode` | 查看 / 切换模式 |
| `/mode chat` | 正常聊天 |
| `/mode trpg` | 跑团模式：只响应指令，不调用模型 |
| `/mode minigame` | 小游戏模式：只响应指令，不调用模型 |
| `/mode <自定义模式>` | 按 id 或名称切换 |
| `/mode off` | 回到聊天模式 |
| `/roll 1d20` | 掷骰，支持 `3d6+2`、`2d20kh1`、`1d8+1d6` |
| `/wiki 原神` | 查游戏 wiki，返回摘要和链接；别名 `/百科` |
| `/game` | 查看已启用的小游戏和指令 |

模式切换后，机器人会发一条当前模式说明。

---

## 二、查游戏 wiki

```
/wiki 原神
/wiki 胡桃 原神
```

| 行为 | 说明 |
|---|---|
| 数据来源 | 只用「模式与插件 → 内置插件」里配置的站点，默认灰机 wiki + 萌娘百科，外文站需自己添加 |
| 是否调用模型 | 查询本身不调用；中文关键词在英文站没匹配上时，会翻一次关键词再搜（可关） |
| 缓存 | 摘要缓存 12 小时，重复查询几乎立刻返回 |
| 失败 | 会写明是哪个站点拒绝访问、超时，还是没收录 |

返回示例：

```
📖 原神 —— 萌娘百科
《原神》是一款由米哈游研发的 3D 角色扮演类开放世界冒险游戏……
🔗 https://zh.moegirl.org.cn/原神
```

灰机 wiki 的每个游戏是独立子站，需要在站点列表里单独添加，例如
`原神|https://genshin.huijiwiki.com`。

外文站写法和中文站一样，直接写域名：

```
泰拉瑞亚|https://terraria.fandom.com
Minecraft|https://minecraft.wiki
```

- 只支持 https 的 MediaWiki 站点（域名后加 `/api.php` 能打开）
- 中文关键词在英文站查不到时会自动翻成英文再搜一次
- 返回的摘要保持原文，不做整段翻译
- 被站点防爬拦截时会提示「拒绝自动访问」

## 三、跑团：检定

| 指令 | 说明 |
|---|---|
| `/check 侦查` | COC 技能检定（d100，按本群房规分级） |
| `/check 侦查 奖励1` | COC 奖励骰；最多 2 颗 |
| `/check 侦查 惩罚2` | COC 惩罚骰；最多 2 颗 |
| `/check 运动 15` | DND 技能/豁免检定：d20 + 加值 对抗 DC 15 |
| `/check 运动 15 优势` | 优势：2d20 取高 |
| `/check 运动 15 劣势` | 劣势：2d20 取低 |
| `/sancheck 0/1d6` | 理智检定：成功损失 0，失败损失 1d6，自动扣减 |
| `/attack 15` | DND 攻击检定，对抗 AC；自然 1 必失，20 重击 |
| `/attack 15 优势` | 优势攻击 |
| `/opposed 运动 5` | DND 对抗检定；5 是对方加值 |
| `/先攻` | DND 先攻：d20 + 先攻加值 |

COC 奖励/惩罚骰会附带十位骰明细：

```
🎲 侦查检定（奖励1）　d100 = 41 / 25 → 失败
（奖励1：十位 [4, 9] 个位 1 取低 → 41）
```

DND 攻击命中后自动结算伤害：

```
⚔ 攻击检定　d20 4 + 20 = 24 / AC 1 → 命中
💥 伤害 1d6 6 + 3 = 9
```

重击掷两次伤害骰，伤害加值只加一次。
伤害来自角色卡的「伤害骰」「伤害加值」字段。

妄想症为裸骰模式：

```
/check 侦查
🎲 侦查检定　1d20 = 10
```

不取目标、不判成败。

## 四、跑团：角色卡
| 指令 | 说明 |
|---|---|
| `/pc new` | 建卡；规则里有 `roll` 的字段自动投骰 |
| `/pc show` | 查看自己的卡 |
| `/pc set 力量 60` | 改单个字段 |
| `/pc set 力量 60 体质 55` | 批量改字段 |
| `/pc set 侦查 60 聆听 50` | 技能也可以直接用 set |
| `/pc del` | 删除当前规则下的角色卡 |
| `/pc clear` | 清空当前规则下的角色卡 |
| `/pc clear all` | 清空自己所有规则下的角色卡 |

技能名支持前缀匹配，例如 `/pc set 格斗 60`。

角色卡按「人 + 规则」保存，不按群。切换规则不会丢卡。
手动改过的当前值（生命、理智、技能）优先，派生值自动重算。

## 五、跑团：规则与房规

| 指令 | 说明 |
|---|---|
| `/rulepack` | 查看本群规则和可用规则 |
| `/rulepack 2` | 切换到第 2 套规则（群主/管理员） |
| `/rulepack coc7th` | 按 id 切换 |
| `/rule` | 查看本群房规 |
| `/rule 1` ~ `/rule 4` | 切换房规（群主/管理员） |

规则可以在管理界面启用/关闭。关闭的规则不出现在列表，已选它的群会回退到第一套启用规则。

房规只影响 `/check` 的大成功/大失败判定。

## 六、小游戏

小游戏默认关闭，在「模式与插件 → 小游戏」启用。启用后直接发指令，不需要 `/game start`。
同一个群可以同时启用多款。

### 每日运势（每天一次）

```
/运势
/lucky
```

### 钓鱼（每天一次）

```
/钓鱼
/鱼图鉴
```

31 种鱼/杂物，图鉴显示每种重复钓到次数。

### 每日 Boss（全群共享，每天一次）

```
/boss
/挑战
```

每人每天一次攻击，全群共享 Boss。Boss 名字和血量每天随机。

### 21 点（按局）

```
/开21
/要牌
/停牌
/再来21
```

### 猜成语（按局）

```
/猜 画蛇添足
/成语
/放弃成语
/再来成语
```

### 文字地牢（按局）

```
/地牢 西幻
/走
/攻击
/防御
/喝药
/逃跑
/背包
/状态
/撤退
/再来地牢
```

10 层线性地牢，西幻 / 克苏鲁 / 科幻三种主题，纯 roguelike。

## 七、错误码

| 错误码 | 含义 |
|---|---|
| `E3101` | 插件/游戏崩溃或加载失败 |
| `E3102` | 插件/游戏超过 3 秒被中止 |
| `E3110` | 插件尝试联网、写文件等禁止操作 |
| `E2003` | 模型超时 |
| `E1301` | 发送失败 |
| `E1302` | `msg_id + msg_seq` 重复 |
| `E5001` | 数据库打开失败 |

插件错误会直接显示在群里；模型错误通常只使用兜底话术。
