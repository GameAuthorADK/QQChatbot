# 常见问题排查

## 启动

### 提示「程序所在路径过长」

Windows 未开启长路径时，整个程序路径必须在预算内（当前构建约 183 字符）。
把文件夹移到更短的位置，例如 `D:\QQBot`。

### 窗口打不开

程序会自动用默认浏览器打开，地址在 `runtime\url.txt`。
如果 WebView2 缺失，安装 Microsoft Edge WebView2 Runtime。

### 提示「凭据无法解密」

这是正常的：`config\secrets.dat` 与当前 Windows 用户绑定。
换机器或换用户后必须重新填写 AppSecret。

### 双击没反应，另一个进程已经在运行

同一文件夹有单文件锁。检查任务管理器是否还有 `QQChatbot.exe`。
不同文件夹是两个独立实例，可以同时运行，但不要用同一个 AppID。

## 连接

### 一直黄点 / 反复重连

按顺序检查：

1. AppID / AppSecret 是否正确
2. QQ 开放平台是否配置了当前公网 IP 白名单
3. 是否换了网络导致 IP 变化
4. 机器人是否被平台限制
5. 日志里是否有 `E1102` / `E1103` / `E1104`

### 群里 @ 没反应

1. 群是否已批准（状态必须是 `active`）
2. 机器人是否真的在群里
3. 是否只 @ 了机器人但没有发送文字
4. 模式是否处于 trpg / minigame（只响应指令）
5. 是否被滥用防护静默
6. 每日额度是否用完

## 模型

### 回复总是兜底话术

查看日志中的模型错误码：

- `E2001` 没有可用 Provider
- `E2002` Key 错误 / 无权限
- `E2003` 超时
- `E2004` 限流
- `E2005` 上下文超限
- `E2006` 返回格式异常

### 试聊正常，群里不正常

试聊不经过 QQ 网关，只验证「提示词 → 模型 → 分段」。
群里不正常通常是网关、群状态、额度或模式问题。

## 插件

### 规则 / 游戏不显示

- 文件必须放在正确目录：`plugins/trpg`、`plugins/minigame`、`plugins/modes`
- 文件名和 id 必须符合规范
- 点「重新扫描」
- 看「加载错误」

### 游戏启用了但指令没反应

- 看是否有其他游戏占用了同名指令（加载错误里会提示）
- 引擎保留指令不能被游戏覆盖
- 文件改动后游戏会自动停用，需要重新启用
- 规则 hook 也需要单独启用

### 插件报错

- `E3101`：代码异常 / 缺少 `handle`
- `E3102`：超过 3 秒
- `E3110`：尝试联网、写文件、启动子进程等被拦截

插件在子进程沙箱运行，不能读密钥、不能联网、不能写文件。

### 规则 hook 不执行

- 规则本身要启用
- 规则文件里的 hook 要单独启用
- 文件改动后哈希变化会自动关闭 hook

## 数据

### 恢复备份失败

- 只接受本程序导出的 zip
- zip 内必须有 `data/bot.db`
- 不允许 `secrets.dat`、绝对路径、`..`
- 旧版本备份会自动补齐表结构

### 清空业务数据后凭据还在吗

在。清空只删群、卡、记忆、日志和启用状态，保留账号配置和密钥。

### 每日游戏没有刷新

检查系统日期。每日刷新按本地自然日，bot 离线跨天会在下一条指令时刷新。
长期统计在图鉴/战绩里，不会随每日状态清空。

## 管理界面

### 打不开 / 403

- 只能用 `127.0.0.1` 或 `localhost` 访问
- URL 必须带 `t=` 会话 token
- 不要从其他机器访问

### 某个页面一直「加载中」

打开浏览器开发者工具看 `/api/state` 是否报错。
常见原因是数据库损坏或插件加载异常，日志里会有详细错误。
