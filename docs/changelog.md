# 版本历史

本项目基于 DeepSeek 开发。

## 0.2.8（2026-11-10）

- 新增：应用窗口、exe 和托盘统一使用 `assets/icon.ico` / `assets/icon.png`；
  打包时自动写入 exe 并复制图标文件
- 调整：记忆整理最多保留 10 条，其中最多 6 条来自最新对话，
  最多 4 条保留历史中权重较高、仍然有效的事实
- 调整：记忆整理按「助手」在句子里的实际含义判断；机器人自称的「助手」
  改写为「我」，人设中作为物品/工具/职业等名词的「助手」和用户对机器人的
  称呼「助手」保持原样
- 调整：自动自检按群累计机器人自己的回复和主动发言，达到设定条数后更新报告；
  不计群友消息
- 调整：自检始终记录文字报告，不再只回 OK；不再输出「状态」，
  固定输出「报告 + 权重」，权重为 0.0–1.0 的一位小数，数字越大问题越突出
- 调整：正常报告的权重为 0.0，不写报告文字，也不注入机器人提示词；
  所有权重大于 0.0 的报告都会影响回复；调用失败记录为「异常」
- 新增：人设稳定页增加「立即自检」按钮，可手动检查最近一段对话
- 调整：自检只检查机器人自己的回复，不评价群友发言
- 调整：自检报告只记录聊天模式，按群保存，同一个群可以保留多条历史报告；
  每群最多 10 条问题内容，0.0 不占名额，最新一条始终保留，
  其余超出时先删除低权重内容；所有群合计最多 200 条报告
- 新增：自检报告和记忆列表改为后端分页，每页 10 条，只返回当前页
- 新增：自检报告可以手动编辑、删除、清空本群；编辑只改文字，
  权重从行末括号读取，括号缺失或数值不合法时该行不生效并显示「不生效」；
  没有合法权重时保存前会确认
- 调整：导入自检报告时可以选择合并追加或覆盖全部，
  覆盖前会再次确认，并按 id 和「群 + 模式 + 时间 + 文字」去重
- 调整：所有群合计最多保留 200 条长期记忆，超出后清掉最久没有更新的摘要
  和对应待整理内容；恢复备份后也会立即裁剪

## 0.2.7（2026-11-09）

- 新增：提示词按 JSON 文件分别导出到 `runtime/prompts/`：人设、接梗提示词、
  主动话题提示词、人设锚点各自一个文件，文件名带当前 bot 名字；每个区域支持对应导入
- 调整：人设页不再单独放「导出提示词」按钮，人设仍会包含在提示词导出里
- 新增：自检报告和记忆都导出到 `runtime/memory/`，自检报告支持导入
- 新增：回复设置支持导出和导入默认设置，文件写到 `runtime/reply/`
- 新增：关键词规则支持导出和导入到 `runtime/keywords/`
- 新增：群列表显示完整群号并支持复制
- 新增：桌面窗口点 X 可缩到 Windows 右下角托盘，也可在「基础设置 → 窗口」
  改成点 X 直接退出（默认缩到托盘）；再次启动会唤起已有窗口
- 调整：标题栏和任务栏的最小化只缩到底栏，不再隐藏到托盘；
  移除主界面顶部的「最小化到托盘」按钮
- 修复：点击任务栏按钮最小化后界面未响应
- 调整：人设自检的独立模型开关改名「启用额外自检模型」，并注明不开启时默认使用主模型
- 新增：自检报告按群 / 人 / 模式只保留最新一条，最多 10 条；问题最多 10 条，
  重复跑偏累计权重，权重越高越优先注入「人设重点避免」
- 调整：回复设置支持按群保存和导出，顶部选择群后单独设置
- 调整：全局默认和分群设置拆成「全局回复设置 / 分群回复设置」两个页签，
  全局监听总开关不再藏在群下拉框的「默认设置」里
- 调整：分群回复设置只保存覆盖项，与全局默认相同的项自动继承，
  并显示「本群已覆盖」提示；「机器人所在的群」同一行显示完整群号和复制按钮，
  全局设置导出/导入仍可用
- 修复：分群关闭主动话题后保存会被当成继承，重新变回开启；
  分条发送、回复不 @ 等开关也改为显式保存
- 调整：全局主动话题改为真正的总开关，关闭后所有群都不主动发言；
  分群启用但总开关关闭时会显示提示
- 新增：分群主动话题提示词支持单独导出/导入，
  文件写到 `runtime/prompts/proactive-<bot>-<群号后8位>.json`
- 修复：记忆整理请求的输出额度太小，思考型模型会把额度用在推理上返回空摘要；
  单次整理改为 8000 token、超时放宽到 180 秒，截断时自动用 12000 再试一次
- 调整：记忆整理提示词改为以「我」指代机器人，不再把机器人写成「助手」；
  旧记忆里的机器人「助手」会在下次整理时改写成「我」
- 新增：记忆页显示待整理进度（人数 / 对话数 / 消息条数），
  并注明按人和模式分别累计；新增「立即整理」按钮，可手动整理待处理对话
- 修复：全局主动话题的「导出提示词 / 导入提示词」提示显示在分群区域，
  现在显示在全局主动话题下方
- 修复：初次进入界面时监听/主动话题选项会先展开再收起，现在默认就是折叠状态
- 新增：群已勾选监听但全局总开关没开时，界面显示提示，日志每个群提示一次
- 新增：带 `union_openid` 时支持同一用户的跨群记忆

## 0.2.6（2026-11-09）

- 新增：群列表显示完整群号（OpenID），支持一键复制
- 新增：人设自检报告和重点问题都限制条数；重复跑偏累计权重，
  权重越高越优先注入「人设重点避免」
- 新增：回复设置支持按群保存，顶部选择群后单独设置回复行为、主动发起话题和监听参数；
  默认设置给新群继承，设置可导出到 `runtime/reply/`
- 新增：带 `union_openid` 时支持同一用户的跨群记忆，其他群摘要会一起注入
- 新增「主动发起话题」设置（回复设置）：后台定时检查，群安静后按概率、冷却和每日上限
  自己开口，不依赖群消息；主动发送失败不会退回被动回复
- 新增：回复风格、接梗提示词、主动话题提示词、人设锚点统一导出到
  `runtime/prompts/`，基础人设仍单独导出
- 新增「人设稳定」设置（人设 / 提示词）：每轮固定注入人设锚点，并可按间隔让模型检查
  回复是否跑偏；自检可单独配置服务商、接口地址、模型和 API Key，并生成自检报告
- 新增：复读与接梗支持自定义「接梗提示词」，按「[梗名]：对梗的解释，应该怎么接」
  一行一个填写；认得出的梗按提示词接，认不出就顺着语气短吐槽，留空只用通用接法
- 调整：今日额度的 Token 总计、输入 / 输出 / 缓存命中排在一起，
  静默人数改成和其他统计一致的标签/数值格式并挪到明细下方；
  去掉 Token 明细里过大的间隔
- 补充：复读与接梗的触发概率、冷却、每天上限、最长字数、方式都加了参数说明
- 调整：方式选项改为「复读和接梗」/「只允许复读」/「只允许接梗」；
  只允许接梗时，模型失败不会退回复读
- 调整：普通监听会把群友原话、机器人回复和最近几条群聊上下文一起写入对话记忆；
  复读 / 接梗不写对话记忆，改为记录类型、频次、用户常用梗和群内常复读内容，
  接梗时会参考这些记录
- 调整：复读 / 接梗的统计和梗记忆只在插件开启时累计，关闭后不再新增
- 调整：复读 / 接梗的冷却、频率、常用梗改由插件自己的私有存储管理，
  核心只提供通用 `plugin_kv`；普通监听对话记忆仍由核心记忆管理
- 修复：接梗时完全没有使用提示词，只会按内置固定风格输出
- 修复：极早期数据库的 `groups` 表没有 `mode` 列时，群列表查询会报错；
  现在启动时会自动补成 `chat`

## 0.2.5（2026-11-09）

- 分条发送消息：原「像真人一样分几条发」改名；句末句号会去掉，问号和感叹号保留，
  连续的问号/感叹号也会保留
- 群聊监听：说明文案改为「需要在 QQ 群里把……」开头；新增群人数下限，
  群人数在「群聊与黑名单」里手填，未填或低于下限的群不接话
- 今日额度：Token 总计显示在最上面，下面拆分输入 / 输出 / 缓存命中；
  只统计真实 provider 返回的 usage，mock 的估算不再计入
- 新增内置插件「复读与接梗」：按概率复读群友的话，或调用模型接一句短梗；
  可设概率、冷却、每日上限、最长字数和方式

## 0.2.4（2026-11-09）

- 新增：独立的「回复风格」提示词，拼在人设之后，专门规定语气和说话方式
- 新增：聊天模式群聊监听。需要在 QQ 群开启全量消息，
  支持接话概率、冷却、每日上限、最短字数、关键词，并按群单独开关
- 新增：回复可以拆成几条短消息发送，可设最多条数和间隔
- 新增：回复时不 @ 用户，改用主动消息（需要群开启「机器人主动发言」）
- 修复：全量消息和 @ 事件共用 msg_id 时可能互相顶掉

  小游戏只响应小游戏指令；`/help` `/mode` `/game` `/wiki` 所有模式通用

- 修复：视觉模型把 content 返回成数组时被判为格式异常，现在能正常解析
- 修复：看图测试超时 20 秒太短，放宽到 45 秒
- 修复：图片被上游 content_filter 拒绝时误报「太大或格式不支持」，现在单独提示
- 修复：原图过大容易被模型拒绝，发送前缩到最长边 1280 并转 JPEG
- 修复：「允许模型看图片」和「测试看图」位置不直观，已调整
